# 🎬 คู่มือการใช้งาน Replay Trigger (สำหรับผู้ใช้)

## ฟีเจอร์ใหม่: สลับ Scene อัตโนมัติเมื่อวิดีโอ Replay เล่นจบ

ตอนนี้คุณสามารถตั้งค่าให้ระบบสลับ Scene กลับไปที่หน้าหลักโดยอัตโนมัติเมื่อวิดีโอ replay เล่นจบแล้ว!

---

## 📋 วิธีใช้งานแบบ Quick Start

### ขั้นตอนที่ 1: เปิด Auto Macros Panel

1. เข้าหน้า **Scoreboard Controller** (หน้าหลัก)
2. คลิกปุ่ม **"Auto Macros"** ที่แถบด้านบน
3. จะเห็นหน้าต่าง **"ระบบควบคุม Macro อัตโนมัติ"**

### ขั้นตอนที่ 2: เปิดใช้งาน Macro

1. มองหา macro ชื่อ **"🎬 กลับหน้าหลักเมื่อ Replay Controller เล่นจบ"**
2. คลิก **toggle switch** (สวิตช์เปิด-ปิด) ด้านขวา
3. เมื่อเปิดแล้ว macro จะมีสีสันและแสดง **"ทำงานอยู่ (ACTIVE)"**

### ขั้นตอนที่ 3: ทดสอบการทำงาน

1. เปิด **Instant Replay Controller**
2. โหลดวิดีโอ replay (คลิก "⚡ คลิกเดียว โหลดและเล่นรีเพลย์ล่าสุด")
3. รอให้วิดีโอเล่นจนจบ
4. ระบบจะสลับ Scene กลับไปที่ **"Main Stream"** โดยอัตโนมัติ!

---

## ⚙️ การปรับแต่ง Macro

### เปลี่ยนเวลารอก่อนสลับ Scene

1. ใน Auto Macros Panel คลิกปุ่ม **"แก้ไข"** (ไอคอนดินสอ)
2. ใน **"ขั้นตอนการทำงานตามลำดับ"** จะเห็น:
   - **ขั้นตอนที่ 1**: หน่วงเวลา 500 ms (0.5 วินาที)
   - **ขั้นตอนที่ 2**: สลับ Scene ไปที่ "Main Stream"
3. คลิกที่ช่อง **"ระยะเวลา"** แล้วเปลี่ยนเป็นเวลาที่ต้องการ (เช่น 1000 = 1 วินาที)
4. คลิก **"บันทึก"**

### เปลี่ยน Scene ปลายทาง

1. แก้ไข macro (ตามขั้นตอนด้านบน)
2. ที่ **ขั้นตอนที่ 2**: คลิกที่ dropdown **"Scene"**
3. เลือก Scene ที่ต้องการสลับไป (เช่น "Replay", "Standings", ฯลฯ)
4. คลิก **"บันทึก"**

### เพิ่มขั้นตอนเพิ่มเติม

คุณสามารถเพิ่มขั้นตอนได้ เช่น:

1. แสดง Goal Alert ก่อนสลับ Scene
2. ซ่อน Source ต่างๆ
3. รอเวลาเพิ่มเติม

**ตัวอย่าง Workflow ที่ซับซ้อน:**
1. รอ 0.5 วินาที
2. แสดง Goal Alert
3. รอ 3 วินาที
4. ซ่อน Goal Alert
5. สลับไปที่ Main Stream

---

## 🎨 สร้าง Macro ของคุณเอง

### ตัวอย่างที่ 1: แสดง Standings หลังจบ Replay

1. คลิก **"+ สร้าง Macro ใหม่"**
2. ตั้งชื่อ: **"แสดง Standings หลังรีเพลย์"**
3. เลือกเหตุการณ์: **"🎬 เมื่อวิดีโอใน Replay Controller เล่นจบ"**
4. เพิ่มขั้นตอน:
   - **+ สลับ Scene**: เลือก "Standings"
   - **+ หน่วงเวลา**: 10000 ms (10 วินาที)
   - **+ สลับ Scene**: เลือก "Main Stream"
5. คลิก **"บันทึก"**

### ตัวอย่างที่ 2: แสดง Goal Alert แล้วกลับหน้าหลัก

1. สร้าง Macro ใหม่
2. ตั้งชื่อ: **"Goal Alert หลังรีเพลย์"**
3. Trigger: **"🎬 เมื่อวิดีโอใน Replay Controller เล่นจบ"**
4. ขั้นตอน:
   - สลับ Scene → "Main Stream"
   - รอ 1 วินาที
   - แสดง Source → Scene: "Main Stream", Source: "Goal_Alert"
   - รอ 4 วินาที
   - ซ่อน Source → Scene: "Main Stream", Source: "Goal_Alert"

## 💡 เคล็ดลับและข้อควรรู้

### ✅ ข้อดี

- **ประหยัดเวลา**: ไม่ต้องคอยสลับ Scene ด้วยตัวเองอีกต่อไป
- **แม่นยำ**: ระบบตรวจจับเมื่อวิดีโอจบพอดี ไม่เร็วไม่ช้า
- **ปรับแต่งได้**: คุณสามารถสร้าง workflow ที่ซับซ้อนได้ไม่จำกัด

### ⚠️ ข้อควรระวัง

1. **ต้องเปิด Macro ก่อน**: ถ้าไม่เปิด toggle switch macro จะไม่ทำงาน
2. **ต้องโหลดวิดีโอให้เล่นจบ**: ถ้า pause หรือหยุดเอง macro จะไม่ทำงาน
3. **หลาย Macros ทำงานพร้อมกัน**: ถ้าเปิดหลาย macros ที่ฟัง event เดียวกัน ทั้งหมดจะทำงานพร้อมกัน

### 🐛 แก้ปัญหา

**Q: Macro ไม่ทำงาน?**
- ตรวจสอบว่า toggle switch เปิดอยู่
- ตรวจสอบว่า OBS เชื่อมต่ออยู่
- ลองปิด-เปิด macro ใหม่
- ดูที่ "ประวัติการทำงาน (Activity Logs)" ว่ามี error หรือไม่

**Q: Scene ไม่สลับ?**
- ตรวจสอบว่าชื่อ Scene ตรงกับใน OBS
- ตรวจสอบว่า OBS ไม่ได้ lock scene
- ลองสลับ Scene ด้วยมือใน OBS ก่อน (ทดสอบว่าใช้งานได้)

**Q: สลับ Scene ช้าเกินไป?**
- ลดเวลาใน "หน่วงเวลา" ให้น้อยลง
- ใช้ 0 ms ถ้าต้องการสลับทันที

## 📚 Event อื่นๆ ที่ใช้ได้

นอกจาก "ReplayVideoEnded" แล้ว คุณยังสามารถสร้าง macro ที่ตอบสนองต่อ event อื่นๆ ได้:

| Event | คำอธิบาย |
|-------|----------|
| `ReplayBufferSaved` | เมื่อกดบันทึก Replay Buffer ใน OBS |
| `MediaInputPlaybackEnded` | เมื่อคลิปวิดีโอ (Source) ใน OBS เล่นจบ |
| `MediaInputPlaybackStarted` | เมื่อคลิปวิดีโอเริ่มเล่น |
| `CurrentProgramSceneChanged` | เมื่อมีการเปลี่ยน Scene |
| `StreamStateChanged` | เมื่อเริ่ม/หยุดถ่ายทอดสด |
| `RecordStateChanged` | เมื่อเริ่ม/หยุดบันทึกวิดีโอ |
| **`ReplayVideoEnded`** ⭐ | **เมื่อวิดีโอใน Replay Controller เล่นจบ** |
